SAC Portfolio Project

This project uses Soft Actor-Critic (SAC) reinforcement learning to experiment with portfolio management and stock allocation.

The model uses historical market data and features such as returns, momentum, volatility, and relative performance to decide how capital should be distributed between different assets.

The project includes:

- Market data collection
- Feature engineering
- SAC reinforcement learning
- Portfolio allocation
- Risk management
- Backtesting
- Comparison against benchmarks such as SPY
- Paper trading with simulated money

The main goal of the project is to test whether reinforcement learning can be used to build a portfolio strategy that balances returns and risk.

This is an experimental and educational project and is not intended as financial advice.
